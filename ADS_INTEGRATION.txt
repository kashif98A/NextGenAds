This file previously described copying the old `ads/` source folder into a
project (SDK 1.2.0, initializing ads with no consent step). That approach is
obsolete: use the :nextgenads library (v1.1.0) from JitPack, and always gather
consent before initializing ads. The old text remains in git history.

Minimum integration, for reference:

  1. app/build.gradle.kts
       implementation("com.github.kashif98A:nextgenads:1.1.0")
       android { defaultConfig {
           manifestPlaceholders["admobAppId"] = "ca-app-pub-XXXX~YYYY"   // REQUIRED
       } }

  2. Application.onCreate()
       adsManager     = AdsManager(this, LiveNetworkMonitor(this))
       consentManager = ConsentManager(this)
       appOpenManager = AppOpenManager(adsManager)        // + other managers
       adsManager.setPreloaderCallback { appOpenManager.loadAd() /* … */ }
       // do NOT initialize ads here

  3. First Activity.onCreate()
       if (consentManager.canRequestAds) adsManager.initialize()
       consentManager.gatherConsent(this) {
           if (consentManager.canRequestAds) adsManager.initialize()
       }

  4. Show ads
       interstitialManager.showAd(activity) { /* next screen */ }
       AdaptiveBannerAdView(adsManager)        // Compose
       NativeMediumAdView(adsManager)          // Compose
